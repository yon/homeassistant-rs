## Session 2: Deduplicate Conversion Functions (COMPLETED)

**What:** Consolidated 3 duplicate `json_to_pyobject` implementations and 2 thin `pyobject_to_json` wrappers into the canonical `py_utils.rs` module.

**Files modified:**
- `py_utils.rs` — Added canonical `pub fn json_to_pyobject()` (~30 lines)
- `hass_wrapper.rs` — Deleted local `json_to_pyobject`, imports from py_utils
- `service_bridge.rs` — Deleted local `json_to_pyobject` + `pyobject_to_json` wrapper, imports from py_utils
- `config_flow.rs` — Deleted local `json_to_pyobject` + `pyobject_to_json` wrapper, uses `py_utils::` at call sites

**Key design decision:** config_flow.rs had a different signature (`Option<PyObject>` vs `PyResult<PyObject>`). Rather than creating a second canonical function, we use the `PyResult` version and call `.ok()` at the 2 call sites that need `Option`. This keeps the API surface minimal.

**Impact:** ~111 lines of duplicate code removed, zero behavior change.
