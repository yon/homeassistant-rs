## Session 2: Deduplicate Conversion Functions (COMPLETED)

**What:** Consolidated 3 duplicate `json_to_pyobject` implementations and 2 thin `pyobject_to_json` wrappers into the canonical `py_utils.rs` module.

**Files modified:**
- `py_utils.rs` — Added canonical `pub fn json_to_pyobject()` (~30 lines)

## Session 3: Split Extension Mode into ha-py-ext Crate (COMPLETED)

**What:** Moved the extension mode (17 files, ~7,135 LOC) from `ha-py-bridge` into a new `ha-py-ext` crate. Cleaned up `ha-py-bridge` to bridge-only.

**Steps taken:**
1. Created `crates/ha-py-ext/Cargo.toml` with extension-specific deps (pyo3 `extension-module`)
2. `git mv` extension/, python/, pyproject.toml from ha-py-bridge to ha-py-ext
3. Created `ha-py-ext/src/lib.rs` from extension `#[cfg]` blocks in ha-py-bridge/src/lib.rs (removed gates)
4. Updated pyproject.toml (name, removed `features = ["extension"]`)
5. Rewrote ha-py-bridge: lib.rs to 15 lines (bridge-only), removed unused deps from Cargo.toml
6. Updated workspace Cargo.toml (added member + dep), Makefile (6 path changes)
7. Fixed build issues: missing `tracing` dep, cdylib linker failure
8. Updated Python tests: `ha-py-bridge/python` → `ha-py-ext/python` in path assertions

**Key design decisions:**
- `crate-type = ["rlib"]` only — cdylib causes linker failures at `cargo build` time because Python symbols aren't available. Maturin overrides this to cdylib when building wheels.
- Kept `ha-py-bridge` name for the bridge crate since `ha-server` depends on it; renaming would touch more files for no benefit.
- No shared conversion crate — extension has `json_to_py`/`py_to_json` in py_types.rs, bridge has `json_to_pyobject`/`pyobject_to_json` in py_utils.rs. Different sentinel handling (UNDEFINED) makes sharing not worth it for ~30 lines.
- `test-rust` Makefile target: added `--exclude ha-py-ext` alongside `--exclude ha-py-bridge` (both need pyo3 which requires maturin develop).

**Impact:**
- `ha-py-bridge`: ~15,600 → ~8,400 LOC (bridge-only)
- `ha-py-ext`: ~7,500 LOC (extension only)
- Feature flag complexity eliminated from ha-py-bridge (was 2 mutually exclusive, now 1)

**Verification:** build, test-rust, test-python (110 pass), lint, lint-alpha — all clean.
